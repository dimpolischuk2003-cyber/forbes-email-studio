# Forbes Email Studio 0.2.11

Дві правки від 21 жовтня 2026 року. Пакет містить також усі попередні зміни 0.2.9 та 0.2.10.

## Зміни

1. Назви Instagram, Facebook, YouTube, LinkedIn та Telegram у спільному футері замінено іконками. Використано відповідні знаки Font Awesome Free 7.3.1, збережені як PNG 64 × 64, які відображаються розміром 24 × 24. Кожна іконка веде за попереднім посиланням соцмережі. Alt і title містять назву для доступності. Для інших контактних URL лишається їхній текстовий підпис.
2. Виправлено ручний вибір світлого оформлення. У 0.2.10 правило @media(prefers-color-scheme:dark) примусово фарбувало .studio-surface у чорний та текст у білий незалежно від вибору в редакторі. Це правило прибрано. Вбудований лист тепер використовує обрану палітру й відповідний color-scheme; світлий має only light. Чорний фірмовий футер залишається чорним в обох варіантах.

Причина, знайдена в поточному коді, узгоджується зі скриншотами: поле вже показувало «Світле», а медіастиль темного режиму пристрою перекривав білий фон у перегляді.

## Встановлення

1. Розпакуйте архів.
2. Відкрийте https://github.com/dimpolischuk2003-cyber/forbes-email-studio/upload/main .
3. Завантажте внутрішні папки app, components, lib, public, scripts, tests і кореневі файли із заміною. Іконки лежать у public/brand/social — цю папку також потрібно завантажити.
4. Commit changes у main → дочекатися Production → Ready у Vercel → відкрити сайт у новій вкладці.

Сайт: https://forbes-email-studio.vercel.app . Номер відповіді API: X-Studio-Version: 0.2.11.

Нові іконки віддаються з домену проєкту після публікації. Скрипт scripts/build-social-icons.mjs відтворює PNG з SVG-джерел; під час звичайної збірки він не запускається. Нових залежностей або змінних оточення немає. У public/brand/social збережено ліцензію, джерела та опис змін.

## Перевірки

- npm test: іконки/їхні посилання, правильна PNG-сигнатура, текстовий запасний варіант для звичайного URL, світла/темна HTML-палітра, регресійні перевірки збереження та надсилання з імітацією eSputnik/Blob.
- npm run build: production-збірка Next.js і TypeScript.
- verify-navigation: справжні події React DOM для перемикання «Темне → Світле» й оновлення iframe srcDoc; дочірні редактори ізольовані. Візуальний браузерний рендеринг цим не перевіряється.
- verify-runtime --storage: production HTTP-сервер, включно з доступом до п’яти PNG без входу.

Після публікації оберіть «Світле», збережіть лист і надішліть новий тест. Зміни не змінюють уже доставлених листів. Вигляд у Gmail/Apple Mail потребує доставленого тесту: ці клієнти можуть самостійно змінювати кольори. Фактичну перевірку поштових програм у цьому середовищі не виконано, реальних листів не надсилали.
