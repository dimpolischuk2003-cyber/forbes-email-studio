# Forbes Email Studio 0.2.10

Єдиний пакет для поточного GitHub/Vercel-проєкту. Містить зміни редактора з 0.2.9 та офіційне оформлення, отримане 19 жовтня 2026 року. Окремо встановлювати 0.2.9 не потрібно.

## Встановлення

1. Розпакуйте архів.
2. Відкрийте https://github.com/dimpolischuk2003-cyber/forbes-email-studio/upload/main .
3. Завантажте ВНУТРІШНІ папки `app`, `components`, `lib`, `public`, `tests` та кореневі файли з архіву. Особливо важлива нова папка `public/brand`: у ній логотип і банер. Не завантажуйте архів як один файл і не створюйте зовнішню папку версії.
4. Натисніть Commit changes у main та дочекайтеся Production → Ready у Vercel.
5. Відкрийте https://forbes-email-studio.vercel.app у новій вкладці. Нова відповідь API міститиме X-Studio-Version: 0.2.10.

Попередні файли GitHub, історію, Blob та ключі видаляти не потрібно. Нових змінних оточення чи бібліотек цей пакет не потребує. Уже відправлені листи не зміняться.

## Офіційне оформлення

- PNG логотипа Forbes із вкладення використовується без змін. Файл розташовано в `public/brand/forbes-ukraine-black.png`.
- Спільний чорний контактний футер із п’ятьма посиланнями: Instagram, Facebook, YouTube, LinkedIn, Telegram. Використано адреси, надані користувачем; LinkedIn доповнено префіксом https://.
- Контактний блок: «З питань підписки на Forbes Digital», support@forbes.ua.
- Текст: «Ви отримали цю розсилку, тому що є читачем Forbes Ukraine».
- Вбудовані дизайни отримують спільне оформлення без індивідуального налаштування кожного браузера. Особисті явно задані logoUrl/footerLinks залишаються перевизначенням.
- Власні старі листи Studio з розпізнаною структурою хедера й футера оновлюються під час підготовки HTML. Вони також показуються з оновленим оформленням у редакторі. Чужі імпортовані шаблони eSputnik зберігають власне оформлення й системні посилання.

## Що встановлено зі скачаного листа

1. Системна відписка в отриманому HTML міститься ПІСЛЯ основного листа. Її URL персональний; він не переносився до спільного футера або коду.
2. eSputnik додав окрему таблицю відписки шириною 600 px і комірку шириною 560 px. Старі мобільні стилі охоплювали тільки клас wrap. Додано правила для цих доданих контейнерів; після повторного отримання HTML також прибирається фіксована мінімальна ширина.
3. Старі кнопки мали відступи в комірці навколо посилання. Для розпізнаних старих листів відступи перенесено в саме посилання, кнопки поміщено в окремі рядки шириною 100%.
4. Банер указував на JPEG сайту Forbes (1200 × 364, RGB, 157604 байти). Під час перевірки цей URL повернув HTTP 200 для запитів з User-Agent браузера та GoogleImageProxy і HTTP 403 для іншого запиту. Це можливе пояснення збою, а не доказ поведінки кожного поштового клієнта.
5. Незмінену копію саме цього банера додано до `public/brand/magazine-subscription-banner.jpg`. Під час рендерингу лише відома адреса цього старого банера замінюється на постійну адресу файлу проєкту. Інші зовнішні адреси не переписуються на цю картинку.

Системна відписка eSputnik зберігається. Її робота не підмінена фіктивним або скопійованим персональним URL. Самостійний лінк «Керувати підписками» не вигадувався: його джерелом має залишатися налаштований у eSputnik шаблон/системний механізм. Текст автоматически доданого eSputnik посилання може залишатися Unsubscribe.

Логотип і копія конкретного банера віддаються зі стабільного домену https://forbes-email-studio.vercel.app. Після зміни домену проєкту слід змінити brandOrigin у lib/brand.ts. Оновлення ще не опубліковане: ці адреси запрацюють після завантаження папки public і завершення деплою.

## Функції з попереднього пакета 0.2.9

- 7 шрифтів, колір виділеного тексту, рамки блоків/виділень, відступи, гнучкий розділювач та вставлення розділювача в текст.
- Поле адреси тестового отримувача на кроці «Аудиторія та час». Лише одна адреса; обрана база для тесту не використовується. Повтор того самого тесту на ту саму адресу не дублюється.
- Посилання на банери, UTM для переходів, окреме вирівнювання положення кнопки та її тексту, клік по площі кнопки.
- Світле/темне оформлення 6 вбудованих дизайнів.
- Збереження назв шаблонів при неповному списку з eSputnik та пошук шаблонів за назвою.
- Завантаження PNG/JPG/GIF/WebP до 3 МБ та імпорт публічного файла Google Drive. Завантажені файли зберігаються в уже підключеному Blob; їхні публічні адреси мають випадкові незмінні ID, службовий control.json через цей маршрут недоступний.

## Перевірки й наступний крок

Пройдено npm test, production-збірку Next.js/TypeScript, React DOM перевірку навігації та перевірки справжнього HTTP production-сервера з імітацією eSputnik/Blob. Перевірено окремо, що PNG та JPEG доступні без входу. Власний логотип звірено за SHA-256 з оригінальним вкладенням. Тест старої верстки використовує структурну копію отриманого листа без персональних коротких посилань та пікселя стеження.

Реальних листів ці перевірки не надсилали. Візуальна перевірка в Gmail та Apple Mail не виконувалася. Після встановлення:

1. Відкрити проблемну чернетку, зберегти її, вписати потрібну адресу в поле тесту і надіслати новий тест.
2. Перевірити банер, обидві кнопки, футер та розташування відписки на телефоні й комп’ютері.
3. Перевірити світлу й темну тему. Поштові програми можуть самостійно інвертувати кольори; повної однаковості не гарантовано.
4. Масове надсилання на реальну базу й реальне планування ще потребують окремої перевірки.

Повністю заборонити отримувачу збереження картинки неможливо.
